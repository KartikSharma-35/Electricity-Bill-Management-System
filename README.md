Electricity Bill Management System ⚡
A console-based C application utilizing structures, functions, and conditional statements to manage customer accounts, calculate consumption, and generate itemized utility bills.

🚀 Key Features
Customer Registration: Captures customer ID, name, and connection type.

Meter Reading & Units: Records previous/current readings to compute total consumption.

Slab-Based Billing: Applies tiered pricing structures based on usage thresholds.

Fixed Charges & Final Bill: Adds standard service fees and outputs a complete itemized invoice.

# Clone and compile

# Run
./electricity_bill  # Or electricity_bill.exe on Windows
